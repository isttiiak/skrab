# @skrab/ipc-types

The typed contract between the Rust backend and the React frontend.

`src/generated.ts` is **generated by `tauri-specta`** from the `#[tauri::command]`
signatures in `apps/desktop/src-tauri/`. It is written on every `cargo build` of the
desktop app (debug profile).

**Never hand-edit `generated.ts`.** Change the Rust type, rebuild, and the TypeScript
follows. That is the whole point: a backend change that breaks the frontend becomes a
compile error instead of a runtime `undefined`.

The file is committed so that `pnpm typecheck` works on a clean checkout without
requiring a Rust build first, and so that diffs to the IPC surface are visible in
code review.

`src/index.ts` is hand-written and re-exports the generated surface plus any
frontend-only helper types.
